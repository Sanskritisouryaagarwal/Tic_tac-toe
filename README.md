# Tic-Tac-Toe Game

## 🧩 Project Overview

Welcome to the **Tic-Tac-Toe Game**! This is a classic 3x3 grid game, built using **JavaScript**, **CSS**, and **HTML**. The game allows two players to play against each other in a simple, interactive environment. Players alternate marking spaces in a 3x3 grid with either an "X" or an "O". The first player to align three of their marks vertically, horizontally, or diagonally wins the game.

## 🎮 How to Play

1. The game starts with an empty 3x3 grid.
2. Player 1 will place "X" on any available spot.
3. Player 2 will place "O" on any available spot.
4. The game will automatically check for a winner after each turn.
5. If a player aligns three marks vertically, horizontally, or diagonally, they win.
6. If all spots are filled and no winner, it results in a draw.
7. You can refresh the page to start a new game.

## 💡 Features

- **Simple User Interface**: Built with minimal HTML and styled with CSS to provide a clean user experience.
- **Interactive Gameplay**: Players can click on grid squares to place their marks.
- **Automatic Win Check**: The game checks for a winner after every move.
- **Reset Function**: Start a new game by refreshing the page.
- **Responsive Layout**: The game is mobile-friendly and adapts to different screen sizes.

## 🛠️ Technologies Used

- **HTML5**: Markup language for the game structure.
- **CSS3**: For styling the user interface and layout.
- **JavaScript**: Logic for gameplay, determining the winner, and managing the game flow.
